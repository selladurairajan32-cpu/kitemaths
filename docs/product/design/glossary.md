# Glossary: one name for each thing (D-037)

Children see one name for each thing, everywhere. Grown-ups' pages may add the precise term, shown next to the child's
name the first time it appears.

| Thing | Child-facing name | Grown-ups' name | Not used with children |
|---|---|---|---|
| An area of the map, e.g. Fractions | island | island (topic) | module, unit |
| The independent test at the end of an island | the big challenge | mastery check ("the big challenge") | mastery check, assessment, "Show what you know" as a title |
| The collection of awards | Badges | Badges | kites (the icon is a kite; the name is Badges) |
| The mental-maths island's activities | Mental maths methods | Mental maths | Methods lab, strategies |
| A step that needs the child to do something | Your turn | — | task, challenge item |
| How well a skill is going | New, Growing, Strong, Mastered, Let's revisit | not started, developing, secure in practice, passed check, mastered, needs review | secure, evidence, accuracy |
| Practice of mixed skills | Practice | practice | Mixed practice drill |
| A worked example the child watches | Watch me / Watch how it works | worked example (full) | — |
| A worked example done together | Together / Try it yourself | worked example (faded) | — |

**Copy rules for child screens:**
- Kip's lines and instructions are about 12 words or fewer.
- Use the words above, not system words such as evidence, accuracy, secure or recheck.
- Detail for grown-ups goes behind "For grown-ups" or on the parent pages.
